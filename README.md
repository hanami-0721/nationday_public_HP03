# langchain实现技术提问澄清助手
一个用 LangChain实现AI助手：非技术人员向开发/技术专家求助时，经常说不清楚问题，甚至问错方向（XY 问题）。本程序通过多轮澄清帮用户整理出规范工单，并在专家追问、给出方案后继续辅助沟通与落地。

## 功能（全流程）

| 阶段 | 能力 |
| --- | --- |
| 提问前 | 多轮澄清现象/环境/报错/复现/期望/实际，识别并标注 XY 问题 |
| 提问时 | 生成规范 Markdown 工单 |
| 专家追问 | 解释术语 + 转述大白话 + 调用工具给出取日志步骤 |
| 专家方案 | 转成可操作步骤 + 调用工具生成只读脚本 + 风险提示 |

## 快速开始
pip install -r requirements.txt        
copy .env.example .env              
python main.py


## 使用命令
- 直接描述问题：进入澄清流程，助手逐轮提问
- `/追问 内容`：把专家追问转译成大白话 + 取日志指引
- `/方案 内容`：把专家方案转成操作步骤 + 辅助脚本
- `exit` / `退出`：退出
